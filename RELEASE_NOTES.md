DeckThemes' CSS Loader, running natively in Steam on Windows through [Millennium](https://steambrew.app). Based on [SDH-CssLoader](https://github.com/DeckThemes/SDH-CssLoader) 2.1.3.

## Highlights

- Install, configure and combine DeckThemes themes in Big Picture and on the Steam desktop, using the same theme folder and formats as Decky's plugin.
- Styles are in place at first paint in every window, with no debugging port or launch option.
- Theme store, stars, account login, update checks, presets, colour and image options, Nav Patch, Unminify Mode and live CSS editing.
- The store and settings open in their own window on the desktop.

## Install

1. Download `css-loader.star` below.
2. Put it in `Steam\millennium\plugins\`.
3. Restart Steam and enable CSS Loader in Millennium's plugin settings.

## Requirements

- A Starlight-capable Millennium.
- In Big Picture, the panel is reached through the [Plugins Hub](https://github.com/DevsNate/PluginsHub-Millennium) plugin. On the desktop, it's in Millennium's sidebar.
